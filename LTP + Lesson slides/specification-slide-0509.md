# 中文第一语言（0509）课件制作规格说明（v3.0）

适用于 IGCSE 0509 中文第一语言各教学单元的 PowerPoint 课件，**尤其是文言文单元**。除非另有明确要求，后续制作均遵守本说明。

**版本：v3.0｜更新日期：2026-11-03**

**依据：**《记李歌》v3.0 重做版（用户明确更喜欢）与 v2.1 重新设计版的对照分析；已在《蜀贾》3 课时课件中完整执行。

**与 v2.1 的关系：** v2.1 的内容准确性、文言知识、提问质量、讲者备注标准（第 1–4 节）全部**继续有效**；v3.0 的变化在于——**把“课堂动作、时间、数据回路”写进每一页**，让课件从“教师讲授＋任务提示”变成“全员应答、间隔提取、出口检测”的课堂操作脚本。第 5、6 节的视觉与字体要求按 v3.0 成品更新。

> 使用方式：下次制作新单元时，说明“请按 `specification-slide-0509.md`（v3.0）制作”，并提供教材页、长期计划和课时数。

---

## 1. 课程内容与准确性（沿用 v2.1 第 1 节）

- 先核对长期计划、教材页和用户提供的截图，再确定结构、课文性质与课时顺序；区分课文、双文本、概括性写作题、阅读活动与写作任务。
- 引文与教材逐字核对（如《蜀贾》采用教材 P124 的“旦食则昏不足”“岁馀”“其去也”，不用异文）。课文原句、教师改写句、迁移新句、参考译文必须清楚标识；**不得把模拟文言句伪装成原文**。
- 不编造教材原文、事实、考试字数、评分换算、政策数据。无法确认的教材题答案，**不给唯一答案**，在隐藏教师页和备注中提示“请对照教参”。
- 每课文本范围明确（如“第 1 课只到药商段”），不提前剧透后一课的结论。

## 2. 单元结构

- 单元前置页：封面 → 总览（课时、产出、教材页）→ 课堂五个动作（学生规则页）。
- 每课固定链：**课封面 → 路线图 → 提取练习＋核对 → 主体活动 → 知识归纳 → 写作/表达 → 出口检测＋核对**。第 1 课没有上一课，用“开场预测”代替提取练习。
- 附录：全文页、备用活动（如良心小巷座位版）、背景卡；**教师参考页（设计依据、易错点）设为隐藏页**，放映自动跳过。
- 一页只做一件事；每页有明确的学生动作，不整页搬教材，不留空白页、重复页、占位内容。

## 3. 课堂设计语法（v3.0 核心）

### 3.1 每页必须标明“怎么做”

- 右上角：**模式标签＋分钟**。模式固定为：全班／独立／同桌／独立→同桌／举牌／白板／四人组（备用页可标“备用”，教师页标“教师”）。
- 左上角：课次＋环节名称（如“第 2 课 · 谁在说”）。
- 每页**底部“产出”条**：写明学生这一页结束时手里有什么（一个答案、一句话、一个词、一张填好的表），不用“了解、感受”之类不可检查的目标。
- 活动页给出 2–4 步流程（含秒/分钟），让学生不问老师也知道下一步。

### 3.2 路线图页（每课第 2 页）

- 列出本课环节及分钟，**总和必须正好 45 分钟**（生成脚本里做代码校验）。
- 写“今天结束时，我能……”的 3–4 条成功标准，学生读后圈出“最没把握的一条”。
- 注明本课产出物、课后作业与教材题号。

### 3.3 五个课堂动作（单元开始时教会，之后每页复用）

1. **先写后说**：所有人先写，再被请说话。
2. **A/B 互译**：同桌各译一半，再互相核对。
3. **举牌 ABC**：“三、二、一”同时亮出，不跟风；老师只数人数，不先评对错。
4. **小白板**：写一个词或一句话，同时亮板。
5. **四人组**：前后桌转身；不挪桌椅（适合小教室）。

被点名的人**只能说“我卡在……”**，不允许说“不知道”。没有举牌／白板时，备注给出“手指 1–4”代替方案。

### 3.4 全员应答与互动密度

- **每课至少 2 次全班同时作答**（举牌或白板），不依赖举手。
- 同一课的活动在**思维动作**上要有变化：回忆 → 预测 → 比较 → 归纳 → 判断 → 书写，不重复同一动作三次。
- 每课至少一次**四人组或同桌互评**，且规定谁是小老师、质疑者、记录、计时（每轮轮换）。人数不是 4 的倍数时备注写补位办法。

### 3.5 间隔提取与数据回路

- 第 2 课起，每课开场“提取练习”：**3 道固定题＋1 道机动题**，白板作答，然后单独一页核对（约 1 分钟）。
- **机动题由上一课出口检测错误率最高的题换成同类新句**，不是原题重复。
- 提取内容每课回溯：第 3 课回收第 1、2 课，而不只是上一课。
- “读不通词单”“出口检测”都是数据：下课拍照或收上来，5 分钟内分三堆（全对／一处错／多处错）并记录各题错误率。

### 3.6 先猜后揭、让学生发现规律

- 能预测的先预测（开场预测、转折句预测），课末**回到开场预测**，看谁改了牌，要求带着一个原文词说明为什么改。
- 词义、虚词、规律让学生先从例句里**分类找规律**（如“取”：购进／索取），再揭示结论；规律页配**至少一道新句迁移**。
- 对课文中的难词用**代入检验**：把现代汉语词放回原句，读通顺才算对。

### 3.7 事实／推断／局限

- 用“原文直接写出（A）／合理推断（B）／证据不足（C）”三选一举牌训练区分，并要求举 C 的学生写出“还缺什么证据”。
- 人物评价区分：行为事实、动机推断、叙述者评价、旁人评价、当代读者评价。
- 寓言不是统计：现实讨论没有数据时，标明“假设情境”，不使用未经查证的数据。
- **每个知识点只出现一次**：词义在读译环节解决，手法与效果在分析环节解决，不在后面页面重复讲。

### 3.8 出口检测（每课末，3 分钟＋1 分钟核对）

- **3 题**：①提取（本课所学）②迁移·新句（无注释的新语篇，如《论语》句）③说理（需要引用原文词）。第 3 课末可改为迁移／说理／回扣开场立场。
- 检测页和**核对页分开**；核对页写答案要点，学生自行订正（用另一种颜色笔，保留原答案）。
- 备注必须写**回收规则**：任一题错误率 ≥30% → 下一课机动题用同类新句再考；并写明“答错这一题的学生，下节课开头回看哪一句”。
- 写作类课：在出口前安排**示范（一个完整分析段）→ 独立写 → 同伴互评/自查**。

### 3.9 写作与表达支架

- 分析段结构固定为“观点—原文—手法—效果”，议论段为“主张—理由—证据—限度（让步与反驳）”；字数是**课堂练习建议**，不冒称考试要求。
- 先出示一个**示范段**，再让学生写；互评用“你是怎样被说服的”式反馈语，不只打勾。

## 4. 文言知识与提问质量（沿用 v2.1 第 4 节）

- 五层目标：准确理解／规律提炼／文本推断／文学分析／评价与迁移；每课写明主目标和可检查成果。
- 允许逐句精读，但**先学生提出理解，再教师针对性纠错**；诊断决定支架强度；参考译文放在“对照订正”页，学生订正时保留原译。
- 文言知识要显性出现在投影片上（例句、观察问题、比较结构、即时应用），不只放备注。
- 提问不预告结论；优先设计解释竞争、反例检验、删改实验、行为与动机区分、证据充分性排序。
- 不假设能走动或重新分组；全部活动适用于小教室。

## 5. 讲者备注（每页必有）

- 备注承担教师专业支持：**答案、关键难句的准确释义与分析、预期错误（具体写出学生会怎么错）、追问、不同解释及判断依据、时间调整办法、安全提醒**。
- 开放题写多种可成立的回答和限制条件，不以单一标签作答。
- 敏感话题（腐败、真实人物）写明安全提醒：只讨论角色的选择与理由，不评价真实个人。
- 备注写明与教材页码、题号的对应（如“对应教材 P125 活动一第 2 题”）；教材争议题标出“请对照教参”。
- 学生页**不出现**课时调整理由、设计方案比较、质量检查条款等元说明；这些只放备注或隐藏教师页。

## 6. 视觉与字体（按 v3.0 成品更新）

- 深色封面＋白底内容页；课封面用一个“大问题”作为主视觉。
- 配色：深蓝（主）＋青绿＋砖红＋金＋紫＋灰；**模式标签配色固定**，同一模式在全单元同色；文本分段使用淡色底（甲＝蓝、乙＝黄、丙＝红，同色对应）。
- 视觉母题随课文选择（《蜀贾》为铜钱：圆形加方孔），重复使用，但不加无功能装饰。
- 字体：**界面与说明文字用微软雅黑，课文原文用宋体**（与 v2.1 的“全部楷体”不同，沿用 v3.0 成品；如需改回楷体，须明确通知）。
- 字号下限：标题 ≥26 pt；正文 ≥14 pt；表格 ≥13 pt；原文 ≥16 pt；字多时拆页，不缩字。教师备注不受限。
- 所有表格与填写结构保持**可编辑文本**，不做成图片；每页形状不得超出页面。
- 缩略图总览检查节奏：连续多页同构（标题＋色块＋三条文字）必须换信息组织方式（时间线、对照路径、矩阵、流程、配对等）。

## 7. 交付与检查

- 文件名：`日期_单元_课文_课时_课堂课件_v3.0_重做版.pptx`（或“修订版”），**不覆盖原课件**，放在对应教学资源文件夹。
- 交付前检查清单：
  1. 每课路线图合计 45 分钟；
  2. 每课 ≥2 次全班同时作答；
  3. 第 2 课起有提取练习（3＋1）；
  4. 每课有出口检测 3 题＋单独核对页＋回收规则；
  5. 每页有模式标签、分钟和“产出”条；
  6. 引文与教材逐字一致；
  7. 渲染后逐页检查文字溢出、重叠、空白页、重复页；
  8. 隐藏页只有教师参考页；
  9. 备注逐页可见。
- 同步生成每课 **Chalk 课时总结**（Learning Intention／Agenda／Exit Ticket／Homework／Differentiation／Resource），文件与课件放在同一文件夹，内容必须与课件一致。
