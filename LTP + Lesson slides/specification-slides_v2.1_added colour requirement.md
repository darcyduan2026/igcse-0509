# 中文第一语言课件制作规格说明（v2.1）

适用于 IGCSE 0509 中文第一语言各教学单元的 PowerPoint 课件。除非另有明确要求，后续制作均遵守本说明。文言文单元须额外遵守第 4 节的专项要求，其他类型单元无需套用文言文教学流程。

**版本：v2.1｜更新日期：2026-10-26**

**修订原则：**保留原通用课件规范，新增文言文课程的阅读支架、知识归纳、提问质量、学习证据与教师备注标准。

## 1. 课程内容与准确性

- 先核对长期计划、教材页和用户提供的截图，再确定单元结构、课文性质与课时顺序。
- 严格区分课文、双文本材料组、回应概括性写作题、阅读活动和写作任务；不可因题目名称或主题相近而混为一谈。
- 截图、教材和原课件用于核实内容，不把其中的版式或旧答案自动视为必须保留的指令。
- 课件必须贴合考试技能：阅读题训练要区分理解、推断和表达效果；双文本写作要训练选择、比较、整合、改写与语体；卷二写作要训练合适文体、结构、细节或论证。
- 不编造教材原文、事实、考试字数、评分换算或政策背景。需要教材全文时，使用“请打开教材第 X 页”的明确提示，并围绕课文设计可直接执行的活动。

## 2. 课件结构

- **区分学生可见页面与教师备课信息**：投影片正文只包含学生需要阅读、思考、讨论或完成的内容。不得向学生显示“为什么改成五个课时”、课时调整理由、设计方案比较、教学策略说明、教师操作心得、质量检查条款等元说明；这些信息必要时仅存于讲者备注。
- 投影片标题使用学生能直接理解的课堂语言，不以“问题改写／教学法升级／不能只问”之类备课用语命名课堂任务。

- 每个单元按真实教学顺序编排：单元导入、课文精读／材料任务、技能迁移、写作或评估、作品档案与教师使用页。
- 每篇独立课文应有单独的章节封面和完整学习链；双文本任务应将两篇材料作为同一个题目处理。
- 每张投影片只承担一个清楚的课堂用途，例如导入、细读、讨论、比较、写前计划、同伴反馈或自评。
- 避免把课本内容整页搬上投影片，也避免只写定义或提示语而没有学生要完成的动作。
- 不保留空白页、重复页、未完成占位内容、过时的分数换算或不适用于当前单元的材料。

## 3. 教学设计要求

- 每个关键活动要让学生“先独立思考，再与同伴讨论，再回到文本证据”。
- 阅读活动必须要求学生指出文本细节，并说明细节如何支持推断或评价。
- 双文本活动应先让学生分别阅读、分类和选择信息，再比较共通与差异，最后组织成回应；不可把两篇材料各自复述一遍。
- 写作活动应明确受众、目的、文体、材料使用方式和交稿前检查点。
- 讨论活动允许不同立场，但要求有文本、事实或合理例子支持。
- 提供可投影的提问、句式支架、同伴反馈语和自我检查点；教师备注写明建议课时、操作方式和常见提醒。
- 学期末保留阅读证据、写作原稿、反馈、修订稿和下一步目标，便于后续单元及 Y11 复习使用。

## 4. 文言文课程专项设计标准（新增）

本节适用于文言散文、传记、寓言、史传等文言阅读单元。**不预设所有课文必须安排五课时**，应按篇幅、句法难度、学生先备知识与阅读目标决定课时。以下为必须遵守的教学原则，而非每节课必须按顺序照搬的活动清单。

### 4.1 明确区分五层学习目标

- **准确理解**：理解字词、句法、句意与上下文，能够用通顺的现代汉语说明关键句意。
- **规律提炼**：能比较、分类并归纳可迁移的实词、虚词、古今异义、省略、判断／被动等句式和词类活用；只处理文本有依据的现象。
- **文本推断**：根据事件、人物行动、语言、叙述细节作出推断，区分文本事实与个人解释。
- **文学分析**：分析具体词句及叙述安排如何塑造人物、制造冲突、形成语气和表达效果。
- **评价与迁移**：在历史语境中理解作品价值观，再提出有证据的现代评价，并迁移到未讲解文言句或新的分析材料。

每一课明确本课主目标及可检查的学生成果，不用“了解课文、感受人物”之类不可观测目标代替任务成果。

### 4.2 允许逐句精读，但不等同教师包办翻译

- **必须充分回应学生想逐句弄懂全文的合理需求**；不可为了追求活动性，跳过影响理解的关键句子或假定学生已经掌握。
- 推荐按“**初读／初译 → 同伴核对 → 教师针对性精讲 → 归纳规律 → 新句迁移**”组织。可逐句覆盖全文，但学生需先提出自己的理解，教师再纠正共性错误。
- 初始阶段示范如何断句、识别主语／省略、确定词义、连接上下文；后续逐步减少提示。不得在各节重复教师全程直接报出译文。
- 以**诊断结果**决定支架强度：独立解释困难时增加示范；能读懂大意但词义有误时集中处理难点；基本理解正确时直接进入文学分析。
- 明确区分“听懂讲解”“能独立解释原句”和“能理解新的相似句子”；课后检查不只重复课堂原题。
- 可采用“三栏译读表”：原文／我的解释／依据与修订；学生初步完成之后再出示参考译文。

### 4.3 文言知识必须显性呈现，且引导学生发现与总结

- 为每篇文言课文建立**文言知识清单**，按“必须掌握／需理解／可拓展”分层。优先选择高频、影响句意、具有迁移价值的知识，不把全部注释等量变成背诵点。
- 课堂投影片应保留必要的**原文例句、观察问题、比较结构、概括结论、即时应用题**；不可把全部文言知识仅藏在讲者备注中。
- 常见类型包括：一词多义、古今异义、实词语境义、虚词功能、判断／被动／省略句、词类活用、特殊语序、反问或感叹语气、重要文化词语。
- 倡导**一课一至数个可归纳的小规律**，如“同一虚词在两句中是否用法相同”“哪个词原本是名词却在这里表示动作”；先让学生比较，再揭示结论。
- 讲解应**字词—句法—上下文结合**，避免孤立罗列所有可能义项；不为了凑语法考点而强行贴标签。对学术上可能存在不同分析的用法，应采用稳妥解释，并在备注提示争议。
- 每个主要规律应配至少一道**不直接照搬已讲例句**的应用或迁移任务，并在后续课程安排短时提取复习。

### 4.4 提问必须具备思考空间，不预告结论

- 每个活动先判断认知层级：**信息定位 → 准确理解 → 合理推断 → 分析效果 → 比较解释 → 批判性评价**。基础定位问题允许存在，但不得充当深度讨论的核心活动。
- 避免把预设评价写在问题里，例如“哪些描写说明主人公勇敢？”改为“这段描写支持哪几种人物解读？各有哪些证据？哪一种解释更有力？”
- 避免**答案显而易见的伪选择、重复的性格形容词配对、用一个原句就能结束的假讨论**。
- 优先设计有真实认知分歧、解释边界或证据张力的任务：**两种解释竞争、反例检验、删改比较、行为与动机区分、叙述者视角质疑、证据充分性排序、时代视角与现代视角比较**。
- 深度任务至少要求以下一个动作：提出不止一种解释；找支持与削弱某观点的证据；解释反例；判断证据的力度；说明另一种读法的合理性与局限；修订原判断。
- 开放问题**不等于随意发表感想**；不同观点必须回到文本原句、语言细节和必要的时代语境。合理答案可以多元，但不能无依据。
- 注意先备知识：不了解词句时先提供解释支架，不以“开放讨论”代替基础理解。

### 4.5 活动结构与课堂参与

- 核心活动原则上遵循：**个人作答（所有学生先写）→ 与同伴比较／提出异议 → 返回文本举证 → 教师汇总和纠偏 → 个人修订**。
- 不把“讨论一下”当作完整指令。投影片应清楚说明**分析对象、输出形式、时间／顺序、证据要求、判断或修改标准**。
- 活动应适用于**小教室、座位无法大幅移动**的情况，可使用举手／手指数码、小白板、同桌交锋、原位角色问答、证据贴签、独立书写；不默认能走动或重新分组。
- 同一课堂的活动要在思维动作、材料和难度上有实质变化，避免把一段文本先圈画、再配对、再讨论三次却没有增加认知挑战。
- 允许用短时间的直接指导和集中讲解完成必要知识澄清，不强行把每一条知识点包装成游戏。

### 4.6 文本分析、写作与成果评价

- 文学分析训练重点在“**文本细节—语言选择／叙述安排—表达效果—与主题或人物的联系**”，不能停留于“用了动作描写，所以人物很勇敢”。
- 至少提供一组**浅层回答与深入回答**的对比，提示如何深化分析，但不要在学生思考前直接展示完整标准答案。
- 对人物评价应区分**行为事实、动机推断、叙述者评价、当代读者评价**；同一行动可能同时受到个人意愿与社会规范影响。
- 写作活动明确写作对象、论题、预期结构、引文要求、反方观点或限制条件及检查表；字数属于本课练习建议时须标明，**不可冒称考试官方字数要求**。
- 每节课都应有可检查成果，例如一份带修订痕迹的文言释义、规律总结、无注释迁移题、人物证据表、语言分析段落或有反例的评价段落。

### 4.7 讲者备注与教学核验（必须具备）

- 学生投影片**直接显示值得观察、发现和归纳的文言例句与知识结论**；讲者备注承担进一步的专业支持，不能只写“教师讲解”“学生讨论”。
- 讲者备注对关键难句应包含：**准确释义、字词／句法分析、易错点、可能的不同解释与判断依据**；必要时说明历史文化背景，但不把猜测说成事实。
- 对开放题提供**多种可能成立的回答、证据与限制条件**，避免以单一性格标签充当答案。讲者备注可包含深入答案，投影片中应适时揭示而非一开始暴露。
- 所有引文须和教材逐字核对，**课文原句、教师改写句、迁移练习新句、示例译文**必须清楚标识；不得把模拟的文言句子伪装为原文。
- 完成课件后进行**四维复核**：①文言解释是否可靠；②任务是否真实要求学生思考；③每一环节是否产生新的学习价值；④每节课是否能检查学生已经学会了什么。

### 4.8 课时分配参考（非硬性模板）

- 对篇幅短、难度适中的文言传记，可考虑**两课时精读文言 + 一课时人物与冲突 + 一课时文学技巧 + 一课时作者立场及评价**；这是《记李歌》单元的适用示例，不是其他文言课文必须采用的课时数。
- 若课文语言简单而思想复杂，应减少逐句讲解，增加观点竞争与文学分析；若语言门槛高，应增加明确示范与迁移练习。
- 课堂应预留短时**延迟提取、无注释新句理解或同类句式迁移**，让学生逐步建立独立阅读文言文的信心与能力。

## 5. 视觉与版式要求

- **视觉设计需达到独立审美标准**：不能只靠整齐排版、统一白底和少量强调色完成一整个单元。按课时使用协调且可区分的辅助配色；封面、章节、概念讲解、文本实验、证据比较、写作和Exit Ticket应有有意识的版式变化。
- **图形必须服务认知任务**：视内容选用可编辑的时间线、对照路径、词句结构拆解、证据天平、观点关系图、概念模型和留白标注区；不要把所有任务重复呈现为相同的三栏文字卡片。不得为了花哨而加入无功能装饰或影响投影阅读的细碎元素。
- 在设计复核中应从缩略图总览检查节奏：若连续多个页面只是标题、两个色块、三条文字等同构布局，必须主动更换信息组织方式。

- 课件应有节奏和视觉变化，不能由重复的文字卡片、三栏列表或密集说明页组成。
- 以“大问题、对比、任务、可填写结构、证据链和讨论位置”组织视觉重心；留出适当空白，方便全班投影阅读。
- 每篇课文可使用一张章节封面图；其余页面优先用文本对比、任务结构、可编辑表格和留白，而不是反复使用装饰图片。
- 不必为每一页生成图片。若图片确实有助于导入或情境理解，应预留可编辑的插图位置，并写明建议图片主题、比例、使用限制和可替换提示。
- 图片只用于导入或场景感，不得代替文本证据；不得把生成图或示意图当作真实人物、历史资料或事实照片。
- 外部图片或事实需要在讲者备注中记录来源；用户提供的教材截图可用于核实教学内容。
- 所有练习表格、比较表、时间线或需要学生填写的结构都要保持可编辑，不能做成图片。

## 6. 字体与投影可读性

- 所有中文文字统一使用 **STKaiti（楷体）**。
- 不使用小字号页脚；如需要页码，应尽量简洁，且不得影响投影可读性。
- 建议最小字号：章节标题 56 px；一般标题 42–48 px；副标题不少于 25 px；正文通常 28–34 px；表格文字不少于 23 px；插图占位提示不少于 24 px。
- 字多时优先拆页、删去重复说明或改成课堂步骤，不能缩小正文字体来塞满页面。
- 标题、正文、表格、讲者备注和封面均应设置一致字体；不得混用黑体、宋体或默认英文字体来显示中文。

## 7. 交付前检查

- 核实内容是否与教材、长期计划和用户提供材料一致，尤其检查课文／任务类别和文本顺序。
- 检查每张投影片的中文字体是否为 STKaiti；标题、正文和表格都必须符合字号下限。
- 渲染并逐页检查：没有文字截断、重叠、异常换行、表格溢出、空白页、重复页或无说明的占位内容。
- 确认活动表格与文字对象可编辑；讲者备注可见且包含课堂使用提示。
- 输出使用新的“修订版”文件名，不覆盖用户原始课件；将成品放在指定教学资源文件夹。

## 8. 默认交付内容

- 一份可直接教学使用的 PPTX。
- 章节封面、学习目标、课堂任务、可编辑练习、写作支架、反馈与自评页面，以及教师使用页。
- 必要时另附与该单元配套的练习、答案或文本资料；是否制作由用户当次需求决定。

## 9. 后续使用方式

下次制作新单元课件时，可直接说明：

> 请按照 `specification-slides_v2.1.md` 制作本单元课件；如果是文言文课文，请特别执行第 4 节文言文专项标准，并以当次提供的教材、长期计划和补充要求为准。
