# 鲁迅《非攻》（节选）课文分析与课时总览

课件：`0509_3.5_短篇小说_鲁迅《非攻》_4课时_课堂课件_v3.0.pptx`｜4 课时，每课 45 分钟｜教材 P129–141（课文 P130–134）｜单元：公平正义（Y11T2，接《蜀贾》之后）

---

## 一、这篇课文值得讲什么

课文是约 2700 字的白话小说节选，**语言门槛低、写法与思想密度高**。所以不逐句翻译，把课时给“人物怎么被写出来”“环境与社会心理”“评价要有证据”。

| # | 值得讲的点 | 课文依据 | 对应技能 |
|---|---|---|---|
| 1 | **节选没有高潮**：停在墨子上路，没见到公输般和楚王，全靠“蓄势”让人想读下去 | “他听不听我，还是料不定的”（P134） | 情节结构；事实 vs 推断 |
| 2 | **作者几乎不直接评价墨子**，只写他说什么、做什么、别人怎么对他 | 对话（P130–131）、打包出发（P131）、沿路（P132） | 正面／侧面描写；证据→推断→效果（卷二描写、记叙） |
| 3 | **对话里有可争议的推理**：墨子用“如果给你一千多盆，你走么？”检验阿廉；“你不懂我的意思”后跑开——解释不止一种 | P130–131 | 推理可靠度；两种解释竞争 |
| 4 | **环境写“没有”**：“看不见……”四次，不写战火，却比战火更不安；社会环境为主 | P132 | 环境描写；删改比较；写作迁移 |
| 5 | **“活该”一句里作者给了两个原因**（习惯认命 / 无衣无食无路可走），没说哪个更主要 | P132 | 人物认定 ≠ 作者态度；证据比较 |
| 6 | **口号 vs 行动**：曹公子（“我们都去死！”）、管黔敖（推沙车）、墨子（“死得于民有利”）；以及“非攻”≠不准备防守 | P132–134 | 区分行为、评价、立场；反例检验 |
| 7 | **“他人评价”只能检验一部分**：毛泽东、胡适评人格立场（节选难检验）；法捷耶夫、王朔评语言文字（可用原句检验） | 教材 P134 | 评价的证据范围；谁在评价 |
| 8 | **公平正义的现代评价**：墨子是英雄吗？区分行为事实、动机推断、文中评价、今天读者的评价 | 教材 P138–141 | 议论：让步 + 反驳 |

**不建议花时间的**：逐句翻译；“国民性批判”“墨子=英雄”作为定论讲给学生；背《墨子》原文。

## 二、为什么是 4 课时

- 教材活动共六大块（导入、文体知识与理解、回应、分析／评论、创作、反思），初读与词义 1 课可完成；人物、环境、评价各需 1 课，每课有一个可检查的产出。
- Y11T2 共 19 课时：《蜀贾》3 + 《非攻》4 = 7，其余用于陌生明代文言、卷一／卷二模拟与错因档案。
- **压缩到 3 课时的做法**：第 1 课并入第 2 课开场（导入 + 初读 + 镜头表缩成 15′），关系图与议论段改课后。

## 四、可直接复制到 Chalk 的课时摘要

### 第 1 课　读通故事
**Learning Intention**：We are learning to read the whole excerpt of 《非攻》, separating what the text says from what we infer.
**成功标准（今天结束时，我能）**：①说清墨子为什么离家、去哪里、想阻止什么；②用代入法解释“辞让、可怜、倚恃、兴风作浪”；③分清“写出的”与“推断的”，判断节选落在情节哪一部分；④画人物关系图并写一句话概述。
**Agenda**：路线图 1′ → 导入（P129）5′ → 初读 6′ → 词义白板 5′ → 镜头表 8′ → 举牌：高潮在哪里 3′ → 关系图 8′ → 一句话概述 5′ → 出口 4′
**Exit Ticket**：①为什么去楚国？②教师自拟新句里的“倚恃”与课文同义吗？③仅凭节选能断定墨子能阻止楚国吗？（不能／不确定：“他听不听我，还是料不定的”）
**Homework**：P135 理解·活动一（词义）；订正出口检测。

### 第 2 课　对话与行动
**LI**：We are learning to analyse how 鲁迅 builds the character of 墨子 through dialogue and action, using evidence → inference → effect.
**成功标准**：①用正面／侧面描写说清一句话的写法与“读者知道了什么”；②判断墨子对阿廉的推理有多可靠；③对“为什么跑开”提出不止一种解释；④写一段观点—原文—手法—效果的分析。
**Agenda**：路线图 1′ → 提取 4′ → 手法速判 4′ → 阿廉推理 8′ → 跑开三种解释 7′ → 删改实验 5′ → 浅层→深入 3′ → 写分析段 6′ → 对照示范 3′ → 出口 4′
**Exit Ticket**：①墨子用什么办法检验阿廉的说法？②新句“成绩单折了又折……”能推断什么、依据词？③“头也不回”能证明他不在乎耕柱子吗？
**Homework**：P136 理解·活动二 ①②③；订正。

### 第 3 课　环境与空谈
**LI**：We are learning to analyse environment description and to tell slogans from actions, using the text rather than assumptions about the author.
**成功标准**：①分清自然／社会环境，比较“直接写战火”与“只写看不见”；②对“活该”提出不止一种解释；③用原文区分口号与行动；④写一段让读者自己推断“被战争摧残”的环境描写。
**Agenda**：路线图 1′ → 提取 4′ → 两种写法 5′ → 环境分类 2′ → “活该” 6′ → 口号与行动 8′ → 非攻与防守 6′ → 环境扩写 7′ → 同伴反馈 2′ → 出口 4′
**Exit Ticket**：①黄尘、减价条子分别是什么环境？②新句“招牌褪色、无人叫卖”的环境与推断；③仅凭“自认是活该”能断定作者认为宋国人活该吗？（不能）
**Homework**：P136–137 活动二 ④；P140 创作① 完成；订正。

### 第 4 课　评价与写作
**LI**：We are learning to evaluate 墨子 and the critics' views with evidence, separating fact, inference, in-text evaluation and modern judgement.
**成功标准**：①给句子标 F／I／N／M；②判断哪些他人评价能被节选检验并检验一条；③比较鲁迅笔下与漫画里的墨子；④写含让步与反驳的议论段。
**Agenda**：路线图 1′ → 提取 4′ → 四类判断 4′ → 评价检验 4′ → 用原文检验 5′ → 两个墨子 4′ → 立场表态 3′ → 证据分类 6′ → 议论段 8′ → 自查 2′ → 出口 4′
**Exit Ticket**：①哪句是行为事实？②“走了三天路所以一定无私”缺什么证据？③P141 第 8 问：公平的过程是否一定产生公平的结果？联系一个情节。
**Homework**：P140 创作② 议论文；P141 反思表；选做：海报（P138）、演讲（P141）。
