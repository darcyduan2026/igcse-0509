# IGCSE 0509 中文第一语言：Y10–Y11 课时简明教学安排

依据《0509 中文第一语言 两年长期计划 修订版 含审计与建议》编排。以下以 **1 个 L 约等于 1 小时** 计算，共 151 小时；若学校每节课为 75–90 分钟，可将相邻课次合并，并保留每学期最后 1–2 课用于归档与错因分析。

每节课仅列出课堂目标和核心活动，不代替详细教案、教材页码或讲义。

## Y10 第 1 学期：文化认同（22 小时）

| 课次 | 本课目标 | 核心活动 |
|---|---|---|
| L1 | 诊断学生阅读与写作起点，建立“文化认同”问题意识。 | 入学短诊断；文化关键词速写；建立作品档案。 |
| L2 | 初读《假黎婆》，辨认人物称呼与叙述视角。 | 圈画称呼、关系和未知问题；小组分享。 |
| L3 | 用人物动作、语言与物件作出有依据的推断。 | “细节—解释—证据”阅读表。 |
| L4 | 理解“一包盐、一斗米”情节中的人物选择。 | 先作个人选择，再以课文语气和行为解释。 |
| L5 | 比较奶奶与“我”的情绪和关系变化。 | 事件线与情绪线并读。 |
| L6 | 从山路、歌声、语言等细节理解归属与记忆。 | 文化冰山活动；由现象推到意义。 |
| L7 | 分析回忆结构和“假黎婆”标题的作用。 | 情节重排；标题再读短答。 |
| L8 | 将阅读细节迁移到描写写作。 | 以人物、物件、场景构思《一个瞬间，看见一个人》。 |
| L9 | 完成并修订一篇描写文。 | 定时写作；同伴反馈；保留原稿与修订稿。 |
| L10 | 认识“新加坡多种族政策”为双文本回应概括性写作任务。 | 导入题目；浏览短文一、短文二；确定两文各自作用。 |
| L11 | 从两则短文区分事实、想法与意见。 | 三色标注；页边记录“可回答哪一项任务要求”。 |
| L12 | 比较两则短文的信息、角度与重点。 | 共通／差异表；选择可用材料。 |
| L13 | 从不同社会需要理解材料中的政策和实践。 | 家庭、学校、社区、新移民四角讨论。 |
| L14 | 学会为受众和目的组织回应概括性写作。 | 分析身份、读者、目的和材料要求；段落规划。 |
| L15 | 完成一次双文本指导式写作练习。 | 限时写作；要求选择、整合和改写两则材料。 |
| L16 | 根据量规改善材料使用和语体。 | 同伴互评；教师反馈；重写一个段落。 |
| L17 | 导入《文化入侵故宫星巴克的伪问题》，区分标题预测与作者立场。 | 看题讨论；带着问题初读。 |
| L18 | 理清议论文的事实、公众争议和作者主张。 | 分段阅读；小组用一句话概括段落功能。 |
| L19 | 识别论点、证据和推理的关系。 | 论点—证据—推理图；评价一处论证。 |
| L20 | 学习举例、对比、反问、类比等论证手法。 | 回到文本找例；说明手法的作用。 |
| L21 | 以文本证据讨论文化空间与商业活动。 | 条件式立场讨论；阅读短答训练。 |
| L22 | 回顾本学期阅读与写作证据，设定下一步目标。 | 作品归档；错因分类；个人目标。 |

## Y10 第 2 学期：文言文与散文（19 小时）

| L17 | 修订写作并建立个人表达错误清单。 | 选段重写；标点、句法、用词检查。 |
| L18 | 完成卷一完整诊断。 | 按真实时限完成；记录时间分配。 |
| L19 | 分析诊断结果并归档。 | 错因会议；个人复习目标。 |

| L22 | 修订议论文中的论据或反驳。 | 证据升级；段落重写。 |
| L23 | 进行卷一阅读技能整合练习。 | 现代文短答与双文本材料小测。 |
| L24 | 归档两篇定时作文并设定目标。 | 自评清单；作品档案整理。 |

## 全程固定安排

- 每周保留一个 30–45 分钟的考试技能时段，即使正在精读课文。
- Y10T2 起每两周完成一则文言短练；Y10T4、Y11T2 加强陌生文言训练。
- 每一项定时任务都保留原稿、量规、反馈、学生反思和一段修订稿。
- 每学期结束前完成作品归档、错因分析和下一学期目标设定。
- Y11T3 停止大型新单元，保留模拟、数据反馈、定向微技能再教学与再测；Y11T4 Study Leave 不另安排课堂。
