# 文言文原文、译文与注释整理规范（Specification）

**版本：** v1.0  
**适用范围：** IGCSE 0509 中文第一语言文言文教学；亦适用于其他中学文言文的学生学习资料、教师备课文档及复习讲义。  
**预期产出：** 一份能够独立阅读、复制到 Word/Markdown、供课堂逐句精读与课后复习使用的中文学习资料。

---

## 一、核心原则

1. **以原文为准，准确性优先。** 优先使用教师提供的教材扫描、截图或指定版本。不要凭记忆补写原文、改字或把不同版本拼接。若原文不全，先核实来源；未经核实，不得假装是教材原句。
2. **先对照翻译，后系统注释。** 同一篇课文固定按照“原文—译文对照 → 分段注释 → 重点文言知识 → 完整译文”的顺序整理。
3. **原文、译文严格对应。** 按自然段或意义完整的句群分行；不得遗漏、跳译或将相隔较远的句子拼在一起。引语、因果和人物行动顺序应与原文一致。
4. **现代汉语通顺，但不脱离原意。** 翻译忠实呈现语义、语气、人物关系、历史背景；遇省略句，可合理补出省略内容，但不能加入原文未交代的事实和动机。
5. **翻译中适量嵌入括号释义。** 与文言字词有直接对应关系的难点，可在译文后用括号提示，如“赠送（遗 wèi）”“拍打（拊 fǔ）”。不要求所有词都注，避免括号淹没句意。
6. **重点注释要覆盖整篇，不只列生僻字。** 包括重要实词、虚词、多音字、通假字、古今异义、词类活用、句式、文化背景、必要的表达效果。
7. **知识点必须能回到原句。** 特别是“为……所……”被动、“名词活用”“而”的不同作用等，要写清具体语义，不只贴语法标签。
8. **面向学生，保持学术准确。** 对有争议的语法归类、专名或版本异文，采用审慎措辞；必要时说明差异，避免把一种解释写成唯一真理。
9. **不要混入课堂PPT制作流程。** 这是一份“原文译文与注释”资料的规范；课时安排、教学活动及幻灯片视觉规则另依课程/PPT规范处理。

## 二、强制输出结构与格式

### 标题和版本说明

固定标题形式：

```markdown
# 朝代·作者《篇名》——原文、译文与注释

> 选自《出处》｜原文依据：教材第 X–X 页 / 指定版本（若已核实）
```

- 不确定的朝代、作者、篇名或出处不得自行编造；可以暂时省略不确定信息。
- 如果教材与其他版本不同，以用户指定教材为主；在文末简要记录必要的异文。

### 第一部分：原文与译文对照【必备】

固定二列表格，列名只能是 **原文**、**译文**：

```markdown
## 一、原文与译文对照

| 原文 | 译文 |
|---|---|
| **[意义完整的原文句群]** | [通顺译文；必要处加（字词：释义）或（原词＋拼音）] |
```

**执行细则：**

- 每行建议为 1–4 个紧密相连的原文句子（可视长度调整），使学生能够一眼核对对应译文。
- 人物对话可单独成行；过长的一段可拆成多行，不能为方便排版随意切断语义。
- 原文保留教材标点和字形，不进行默默“校正”。
- 译文使用现代汉语，不机械逐字排列；关键词用括号加释义，保留必要的古今义对照。
- 括号提示应放在对应译文片语后；不在一处堆积多个无关知识点。
- 在单元格确有分段需要时，Markdown 可使用 `<br>` 显示换行；不插入多余空白行。

**示例 A：《记李歌》——多音字、句式及词类活用**

| 原文 | 译文 |
|---|---|
| **以白金遗其母，欲私之。** | 他拿银子（白金）赠送给李歌的母亲（遗 wèi：赠送），企图与李歌私通（私之）。 |
| **俱为贼所执。贼悦李有殊色，欲杀其夫而妻之。** | 李歌夫妇两人都被贼人抓住（为……所……：表示被动）。贼人见李歌容貌出众（殊色），想杀掉她的丈夫，再娶她为妻（妻之：娶她为妻）。 |
| **倡犹能有是哉！** | 就连歌妓（倡）尚且能够有这样的品格（是）啊（哉：感叹语气）！ |

**示例 B：《蜀贾》——词义与故事细节**

| 原文 | 译文 |
|---|---|
| **请益则益之不较，于是争趋之，其门之限月一易，岁馀而大富。** | 顾客请求多给一些药材（请益），他就增加分量（益之），从不计较。于是人们争先恐后地赶往他的店铺（趋之），店门的门槛（限）每月都要更换一次（月一易）；过了一年多（岁馀），他便发了大财。 |

### 第二部分：分段重点字词注释【必备】

每段按照以下模板排版：

```markdown
## 二、分段重点字词注释

### 第一段：［概括这一段的主要内容］

**原文：**

［与第一部分一致的原文，不随意改动］

- **词语（拼音）：** 在本句中的意义；必要时说明语法或语境。
- **句式：** 说明结构、现代汉语顺序及本句实际含义。
```

**注释选取顺序：**

1. 影响句意的关键词、实词、多音字（如“遗 wèi”“贾 gǔ”“拊 fǔ”）。
2. 易错虚词和逻辑关系（如“乃、则、而、其、之、虽、犹”）。
3. 古今异义、词类活用、特殊句式与省略成分。
4. 必要的文化或历史背景、古代称谓、官名与修辞表达。

**示例 C：《苦斋记》——完整的短段落注释**

**原文：**

山去人稍远，惟先生乐游。樵歌出林，则拊石而和之。人莫知其乐也。

- **去：** 距离，不是现代汉语常见的“前往”。
- **稍：** 略微、有些。
- **惟：** 只有。
- **樵歌：** 樵夫的歌声；“樵”指打柴的人。
- **拊（fǔ）石：** 拍打石头；“拊”指拍打。
- **和（hè）之：** 应和樵夫的歌声；“和”在这里读 hè。
- **则：** 就、便，连接先后情境。
- **而：** 表示动作承接，连接“拊石”和“和之”。
- **莫：** 没有人。

**示例 D：《记李歌》——特殊句式和词类活用**

**原文：**

俱为贼所执。贼悦李有殊色，欲杀其夫而妻之。

- **俱：** 都、一起。
- **为……所……：** 典型的文言被动句式；“俱为贼所执”即两人都被贼人抓住。
- **执：** 抓住、捉拿。
- **殊色：** 特别出众的容貌。
- **妻之：** “妻”由名词活用为动词，意为娶她为妻；“之”代指李歌。
- **而：** 连接“杀其夫”与“妻之”，表示动作先后承接。

### 第三部分：本课特别值得掌握的文言知识【必备】

标题可写“本课重点文言知识”，但必须保留如下 **二列表格**：

```markdown
## 三、本课特别值得掌握的文言知识

| 原文 | 需要引导学生发现的知识 |
|---|---|
| “［原句］” | **知识类别：** 准确解释这句的具体现象、作用及意思。 |
```

**内容要求：**

- 知识点来自原文；精选能体现文言阅读规律的典型例句，不是把第二部分每条词语机械重抄一遍。
- 优先包括：重要实词/一词多义、虚词辨析、古今异义、词类活用、判断句/被动句/倒装句/省略句、固定句式和语气表达。
- 与文本密切相关的比喻、反问、对比等语言表达也可列入，但必须区分语法现象和修辞效果。
- 同一个虚词在文章中出现不同用法时，优先并列比较其**在本句中的意思**，而不是罗列词典全部义项。

**示例 E：标准知识表（综合《记李歌》《蜀贾》）**

| 原文 | 需要引导学生发现的知识 |
|---|---|
| “以白金遗其母” | **多音字与实词：** “遗”读 wèi，意为赠送；“白金”指银子。 |
| “吾闻县令为风化首” | **实词：** “为”表示担任、作为；“风化”指社会风俗和道德教化。 |
| “乃真贼尔” | **虚词与判断：** “乃”表示强调判断，相当于“才是”；“尔”加强句末语气。 |
| “吾先杀汝而后自杀尔” | **虚词：** “而”表示动作先后承接。 |
| “俱为贼所执” | **被动句：** “为……所……”表示被动。 |
| “欲杀其夫而妻之” | **词类活用：** “妻”由名词活用为动词，意为娶她为妻。 |
| “倡犹能有是哉” | **虚词与感叹：** “犹”指尚且；“是”指这样的品格；“哉”表达感叹。 |
| “卖药于市” | **状语后置：** 地点介词结构“于市”置于动词之后，现代汉语译为“在市场上卖药”。 |
| “不亦怪哉” | **固定反问句式：** “不亦……哉”相当于“难道不……吗”，突出作者的批判性语气。 |

### 第四部分：完整译文（不含注释）【必备】

```markdown
## 四、完整译文（不含注释）

［从第一句到最后一句的连贯现代汉语译文。
不保留拼音、逐词解释、注释括号或文言语法标签。
保留自然段和人物引语。］
```

- 这是第一部分译文的**去括号、通顺整合版**，不是重新发挥写一篇改写故事。
- 不删掉原文内容，不添加人物心理活动或作者未明说的价值判断。
- 段落、说话者、代词指向与前文保持一致。

**示例 F：《苦斋记》某段的“去注释版”**

> 这座山离人烟有些远，只有先生喜欢在这里游玩。樵夫的歌声从树林里传来，先生便拍打石头应和歌声。别人都不知道他的乐趣。

> **说明：** 以上仅演示某一段的写法。正式整理整篇课文时，本节必须给出全篇完整译文，不得只给片段。

## 三、译文中括号注释的统一风格

| 情况 | 推荐写法 | 不建议的写法 |
|---|---|---|
| 多音字 | “赠送给她母亲（遗 wèi）” | “遗（读音有多种，此处涉及复杂演变……）” |
| 古今异义 | “距离人烟较远（去：距离）” | 不说明易被误认为“前往”的“去” |
| 重要实词 | “拍打石头（拊 fǔ）” | 只写“拍石头”，却在全篇不解释“拊” |
| 特殊句式 | “两人都被贼人抓住（为……所……：被动）” | 生硬翻译为“都为贼所拿了” |
| 词类活用 | “娶她为妻（妻之）” | 只写“妻子她”或不解释“妻”的动词用法 |
| 语气表达 | “难道不是很奇怪吗（不亦……哉）？” | 把反问句翻成平淡陈述句 |

**取舍原则：**

- 注释只标需要特别留意的表达。流畅阅读最重要，不要求每个词后都有括号。
- 拼音仅标易误读、多音或少见字；使用普通话拼音并标调，如 wèi、fǔ、gǔ、hè。
- 如果一个词在第二部分已解释，第一部分可只保留简短提示；两者分工是“对照理解”与“系统掌握”。
- 如学生需要更简洁的课堂阅读版，可减少第一部分括号数量，但**不删减第二、三部分的关键知识点**。

## 四、常见错误与纠正规则

| 常见问题 | 必须如何避免 |
|---|---|
| 引用了与教材不一致的原文 | 对照用户指定教材逐字核对；异文单独说明，不混写。 |
| 意译过度，暗自加入动机 | 区分原文事实与合理推测；译文只给文本可支持的信息。 |
| 翻译正确但遗漏特殊句式 | 对被动、倒装、省略、活用等单列解释或在重点知识表归纳。 |
| 误用现代汉语常见义 | 回到语境核对“去、走、遗、妻、乃”等词在原句中的含义。 |
| 将修辞效果当成字词本义 | 先释词，再解释比喻、夸张、反问等的表达效果。 |
| 完整译文和对照译文互相矛盾 | 定稿前对照检查人称、动词、否定、时间顺序、人物关系。 |
| 只给完整译文，没有原文对照与注释 | 四个必备部分均不可缺。 |
| “重点知识”变成普通词语清单 | 对应完整原句，并指出词义、结构、句法或语气的可迁移规律。 |

## 五、可选的教学补充（非必备）

教师**明确要求**时，可在四个必备部分之后增加简短的“思想与批判性阅读”内容；例如分析《记李歌》中“倡犹能有是哉”体现的作者赞扬与社会身份预设。补充内容要清楚标明：**这是文学分析，不是原句词义或译文的一部分。**

默认不增加大型课堂活动、课时计划、PPT视觉说明或无关的背景介绍。

## 六、交付前质量检查（逐项完成）

- [ ] 全文与指定教材或底本逐字对应，顺序、标点、引文完整。
- [ ] 第一部分为“原文｜译文”二列表格；所有原文均有对应译文。
- [ ] 第一部分括号注释准确、简短且置于相应译文之后。
- [ ] 第二部分按意义段落附原文与列表式注释，读音与词义核实。
- [ ] 第三部分为“原文｜需要引导学生发现的知识”二列表格，含可迁移的句法知识。
- [ ] 第四部分有覆盖全篇、没有括号注释的连贯完整译文。
- [ ] “之、其、而、为、乃”等代词和虚词根据**具体上下文**解释，没有套用同一释义。
- [ ] 所有古代称谓、官职、历史背景和版本差异的说明有据可依。
- [ ] 排版可直接粘贴到 Markdown、Word 或学习平台；中文标点与拼音规范。
- [ ] 不将猜测、课堂设计理由或教师内部说明混入学生译文正文。

## 七、未来可直接复用的请求模板

复制以下提示并替换方括号部分：

> 请按照《文言文原文、译文与注释整理规范（Specification）》为【作者《篇名》】制作完整学习资料，依据我提供的【教材页码/原文/指定版本】。输出四部分：①原文与译文对照表（重点词语在译文中加简短括号释义）；②按段落排列的原文及重点字词注释；③“原文｜需要引导学生发现的知识”二列表格；④不含注释的全篇现代汉语译文。必须与底本逐字核对，注释着重实词、虚词、多音字、古今异义、词类活用、特殊句式及重要语气，不要缺段、不要编造，也不要把教学活动混入正文。
