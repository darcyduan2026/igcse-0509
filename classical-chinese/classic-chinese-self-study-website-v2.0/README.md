# 文言自学网站 v2.0（IGCSE 0509 · 线装书版）

这是 v2.0：换了新的视觉与首页，内容、数据、功能与原版相同。原版保留在上一级的 `classic-chinese-self-study-website/`，页面左下角有“回到原版”链接。两版使用同一个 localStorage 键，学习记录互通。

v2.0 新增：左侧书脊式导航；首页竖排题记（取自“继续上次”或《湖心亭看雪》）与两册书的书脊书架；读原文页新增“竖排”开关；注释字词改为红点标记；手机上书脊折叠为顶栏。

**首页（线装书封面）**：两本书做成线装书封面（`shelf.css`）：《匠心》靛蓝布面、《采文》枣红布面，颜色在 `shelf.css` 顶部 `.jx` / `.cw` 的 `--vc` 里改；两本书中间是“怎么用这个网站”说明笺（`app.js` 的 `pageHome`）；单元做成封面下方的册签。

**主站里的字词练习**：练习引擎在根目录 `practice.js` / `practice.css`。
- 每篇文章的标签页顺序为：读原文｜主旨与作者｜IGCSE模拟题（原“练习”，教材习题）｜字词学习与自测。“字词学习与自测”最上面是这篇的词语卡片，然后是字卡→配对→选义→用法 四关，再下面是“更多练习”（归类、点字、打印小测、每日一练）。`app.js` 顶部 `PRACTICE_ALL = true` 表示全部 26 篇都有；改成 `false` 并在 `PRACTICE_TEXTS` 里列出 `"单元id.文章id"` 可只开放个别篇。题数不足的篇会自动减少题数或隐藏“用法”一关。
- 单元页底部“本单元综合练习”：字卡、选义、配对、用法辨析、归类、点字、打印小测，范围为本单元；题太少的显示为灰色。
- 侧栏“练习”（`#/p`）：八种活动 + 可选范围（全部／某书／某单元／某篇）。每日一练入口也在首页。
- 路由格式：`#/p/<活动>/<范围>`，活动为 `daily mc cards match usage sort find print`，范围如 `all`、`b:caiwen`、`u:u1`、`t:u1.maigan`。

# 文言自学网站（IGCSE 0509）

静态网站，无需构建。打开 `index.html` 即可使用，或用 GitHub Pages 发布。

## 发布到 GitHub Pages

仓库 Settings → Pages → Source 选 "Deploy from a branch"，Branch 选 `main`，文件夹选 `/ (root)`。
发布后网址为：`https://<用户名>.github.io/igcse-0509/classical-chinese/classic-chinese-self-study-website/`

## 内容来源与版权

- 《采文》原文：明代作品，公有领域，依《采文》（华语教学出版社）的选篇照录。
- 《匠心》原文：明代作品，公有领域，依教材《匠心》课文页面（`classic-chinese-in-coursebook-《匠心》/` 里的页面图片）逐字录入；“拓展：课文省略的典故段”取自教师整理的阳明子讲义，不是教材原文。
- 注释、译文、文章主旨、练习题、答案要点、词语卡片：本站自编，不是《采文》原书内容。

## 文件

- `index.html` / `style.css` / `app.js`：页面与逻辑
- `data/jx1.js` … `data/jx5.js`：《匠心》五个单元（每单元一篇文言文：记李歌；节庵方公墓表（另有拓展篇）；蜀贾；湖心亭看雪；《天工开物》序），挂在 `window.JIANGXIN_UNITS`
- `data/unit1.js` … `data/unit5.js`：《采文》五个单元的数据（每单元四篇，共 20 篇），挂在 `window.CAIWEN_UNITS`
  - 第一单元 借事譬喻 · 第二单元 怀人寄情 · 第三单元 著文为实 · 第四单元 隽永小品 · 第五单元 理性光辉
- 新增单元：复制一个数据文件，改 `id`（全站唯一）、`title`、`texts`，并在 `index.html` 里加一行 `<script>`。单元可加 `term:"两年计划 · Y10T2 · 1.4"`，会显示在单元标题下。
- 新增一本书：在 `app.js` 顶部的 `BOOKS` 里加一项，首页会自动多一张书卡。

## 页面

- `#/` 首页：《匠心》《采文》两本书的入口，以及“继续上次”
- `#/b/jiangxin`、`#/b/caiwen` 书页：该书全部单元与文章，显示做题进度；`#/b/jiangxin/words` 该书词语卡片
- `#/u2` 单元页；`#/u2/wangmian` 文章页（读原文 / 练习 / 主旨与作者）；`#/u2/words` 单元词语卡片
- `#/words` 两本书的全部词语卡片（实词、虚词、特殊句式）；`#/method` 三遍读法

## 说明

- 第二至第五单元的原文逐字取自 `文言文资源 自学资料/` 里的单元 Word 文件；注释、译文、主旨、练习与答案要点、词语卡片按第一单元的做法重新编写，没有照搬 Word 文件里的教材习题与答案。
- 分值（每题 `marks`）是本站自定的估计，教材本身没有给出；多小题的题目每小题 1 分。

- 《匠心》的注释、译文、练习与答案同样是本站自编；个别注释（如“其与几何”“更定”）的释义与教材注释一致；练习题参考了教师课堂总结里的出口检测，但不是教材原题。
- 《匠心》课文里的“……”表示教材删节，页面上以“（此处原文有删节。）”标出。

## 数据格式

- 原文段落里用 `[[词|拼音|注释]]` 标注（拼音可留空：`[[词||注释]]`）。
- 练习题 `type`：`mc`（选择，自动判分）、`short`（简答，自评）、`explain` / `who`（多小题，自评）。
- 学习记录保存在浏览器 localStorage，不上传。
