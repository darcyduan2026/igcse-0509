# 打磨记录（首页两本书 · 三方向初稿）

环境说明：本机没有 Python 版 playwright，`polish.py shot` 不能用；改用 Chrome 无头模式按 1440 宽逐屏截图，再逐张打开看，效果等价。

## A 线装封面
- 第 1 轮看到最伤的三处：① 四眼线像括号不像缝线；② 竖排的“6”“20”阿拉伯数字被转歪；③ 大片靛蓝太平，缺少古籍锦面的质感。
- 改了：线改成连续竖线＋四个孔＋横向绕线＋阴影；数字全部改中文数字；加回纹锦面暗纹。
- 第 2 轮：认真看，三处都已解决，没有值得再改的三处。

## B 函套书根
- 第 1 轮：① “第一册”章被挤成两行；② 整体像一块平面面板，不像函套，且偏小、页面下半空；③ 凹槽缺深度。
- 改了：章改单行；整体放大（600 宽、册高 84）；加凹槽内壁阴影和函套底部渐暗。
- 第 2 轮：通过。

## C 翻开的古籍
- 第 1 轮：① 左右页放反（古籍从右往左读，《匠心》应在右页）；② 书名栏小字溢出版框；③ 内容只占上半页。
- 改了：左右页互换；书名栏改成竖排 flex，小字并入同一栏；页高收到 486 并收紧栏宽字号；《采文》第五卷篇目曾溢出版框，缩字号解决。
- 窄屏：栏改固定宽度、可左右滑动，书名栏吸附在右侧。
- 第 2 轮：通过。

## 已知取舍
- C 的篇目小字 13px，比网站正文小；这是“夹注”版式的代价，只在 C 里出现。
- 三版都是首页“书架”区域的替换稿，左侧导航栏和下面的“怎么用”“练习入口”不变，本稿里没画。
