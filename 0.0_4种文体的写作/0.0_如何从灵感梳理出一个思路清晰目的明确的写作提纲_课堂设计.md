# 0.0 如何从灵感梳理出一个思路清晰、目的明确的写作提纲

IGCSE 0509 Chinese First Language · 描写文写作思维训练（修订版 v1.3）
课件：`0.0_如何从灵感梳理出一个思路清晰目的明确的写作提纲.pptx`（15 页，每页有讲者备注）
题目：“或者，描写你和你阔别已久的儿时好友偶遇的场景和你的感受。”

**v1.1、v1.2 的修订**
1. 主题不再一开始就给出。顺序改为：头脑风暴收集素材 → 呈现“零散、缺少写作目的”的状态 → 提出核心问题（写这些碎片的目的是什么？要体现作者一个关于什么的思想？）→ 由“曾经的霸凌”这个灵感引出“成长”。
2. 成长的是“他”（儿时好友），不是“我”。“我”是叙述者和见证者：在车站遇见他、想起他的过去、看见他的现在，并写下我的感受。全课的对比、回忆、情节、手法都按这个视角改写。
3. （v1.2–v1.3）**不在一开始告诉学生“写作需要主题”，也不先展示步骤**。封面之后第一页就是学生的头脑风暴（题目放在副标题里，不单独做读题页）；六步路线图撤掉，页面底部的进度条只显示已讲到的步骤；前两页学生页完全不出现“主题”二字；“目的”的重要性由第 3 页“没有目的 / 有了目的”的对比让学生自己发现，然后才点明“这句话，就是文章的主题”。

## 一、可直接复制到 Chalk 的区块

**Learning Intention**
学会从一堆零散的想法出发，按“素材 → 主题 → 结构 → 情节 → 描写手法 → 提纲”的顺序追问自己，写出一份每个选择都能解释的写作提纲。

**今天结束时我能……**
1. 看出一堆素材“零散、没有目的”，说明“目的（主题）”对一篇文章为什么重要，并用一个灵感找到主题。
2. 分清“谁在变化（他）”和“谁在见证（我）”，并解释写成长为什么需要“过去的他”与“现在的他”的对比。
3. 解释为什么这个主题选时间线而不是地点线，以及回忆在结构中的作用。
4. 说明每个描写细节让读者看见了他的什么变化。
5. 独立写出一份提纲，并向同桌解释自己的每一个选择。

**Agenda（课堂建议，可按班级调整）**
| 环节 | 课件页 | 建议时间 | 学生做什么 |
|---|---|---|---|
| 头脑风暴（含读题）＋“目的”追问 | 1–2 | 6′ | 读题；看碎片；白板写“写这些的目的是什么” |
| 目的 → 灵感 → 成长 → 谁在成长 | 3–5 | 12′ | 比较“有/没有目的”；回答追问；同桌说“他的变化落在哪里” |
| 对比＋结构 | 6–8 | 12′ | 举牌 A/B；写“因为主题是……所以选……” |
| 回忆＋情节＋手法 | 9–11 | 14′ | 说出回忆的三个作用；同桌补充一个手法细节 |
| 总结＋示范 | 12–13 | 6′ | 接龙说出六步的问题 |
| 独立提纲＋检查 | 14–15 | 15′＋5′ | 独立写提纲；同桌追问；写反思句 |

合计约 70 分钟，可拆为两节 45′（第 1–8 页为第一节；第 9–15 页＋独立提纲为第二节），也可压缩（每页备注里有“压缩办法”）。时间是课堂建议，不是考试规定。

**Exit Ticket**
反思句：以前拿到题目，我先_______；现在我会先问：_______。
再加一问：把你的提纲交给同桌，对方能说出“谁变了、怎么变”吗？

**Homework**
把提纲扩写成一篇描写文（字数课堂建议，不是考试规定）；扩写前先改好同桌质疑的两处。

**Differentiation**
- 需要支架：参考第 13 页示范，换成自己的素材，每项先写出“因为”。
- 拓展：尝试不同于示范的主题、视角或结构（如倒叙、双线），并写明选择理由。

**Resource**
课件、第 13 页示范提纲、第 14 页提纲任务页。

## 二、教学逻辑（主线）

素材选择 → 主题确定 → 结构设计 → 情节组织 → 描写手法 → 写作提纲

- 素材本身是零散的；让素材有方向的，是写作的目的（主题）。学生先看到“零散”，被问“写作的目的是什么”，通过“没有目的 / 有了目的”的对比发现它的重要性；主题再从某个灵感里长出来（本课：曾经的霸凌 → 成长）。
- 主题决定结构；结构组织情节；描写手法帮助呈现“他”的变化；全部内容共同服务于主题。
- 两个角色：他＝变化的人；我＝见证的人。读者通过“我”的眼睛看见他的变化，通过“我”的感受体会成长。
- 全课以教师追问为主线。每页只有一个核心问题，答案由点击动画控制，不在追问之前出现。

## 三、五个核心问题在课件中的位置

| 核心问题 | 回答它的页面 | 怎么回答（不是只告知结论） |
|---|---|---|
| 1 为什么不能只停留在寻找素材？ | 第 2、3、4 页 | 先摆出六个零散的碎片，让学生看见“没有联系、没有目的”；再问“写这些碎片的目的是什么”，白板作答；第 3 页让学生比较“没有目的 / 有了目的”的同一组碎片，发现目的（主题）的重要；第 4 页由“曾经的霸凌”一个灵感引出“成长” |
| 2 为什么写成长需要对比？ | 第 5、6 页 | 先分清“谁在变”（他）；再并排呈现“过去的他/现在的他”；最后点出“只写现在，读者不知道他变过” |
| 3 为什么时间线比地点线更适合？ | 第 7、8 页 | 先让学生举牌选择并保留地点线的优点；再用四步推理（主题 → 变化 → 并排比较 → 过去与现在都出现）检验两种结构 |
| 4 为什么回忆能连接过去与现在？ | 第 9、10 页 | 画出“触发 → 过去的他 → 回到现在”的路径，说明回忆同时完成转入过去、建立对比、表达主题三件事；回忆由“我”发起，变化主体仍是“他” |
| 5 为什么描写手法必须服务于变化？ | 第 11 页 | 同一手法分“过去的他/现在的他”两栏对比；检验：删掉这个细节，读者还看得见他的变化吗？ |

## 五、示范提纲（第 13 页）

主题：他的成长　视角：我是见证者　结构：时间线（现在 → 回忆 → 现在 → 结尾）

| 部分 | 主要情节 | 描写手法 | 为主题做什么 |
|---|---|---|---|
| ① 现在·偶遇 | 火车站，我偶遇多年不见的儿时好友；他的一个动作让我想起往事 | 环境：站台人流；外貌：他的变化；一个触发回忆的细节 | 自然转入回忆 |
| ② 回忆·过去的他 | 小时候他被同学欺负，我在一旁看着；他低着头，不敢开口 | 动作：低头、躲避目光、双手紧握；语言：吞吞吐吐 | 立住“过去的他” |
| ③ 回到现在·现在的他 | 站台上他遇到类似的冲突，抬起头，平静说出想法，主动解决 | 动作：抬头、直视对方；语言：主动开口；我的心理：惊讶 | 与②对比，变化显现 |
| ④ 结尾·我的感受 | 我意识到他变了：惊讶、佩服，心里有感慨 | 我的神态与心理：微笑、感慨；环境：列车远去 | 点明成长，回应“感受” |

这只是一个示范方向。学生可以选择其他合理的故事、冲突类型、视角和主题。

## 六、哪些内容来自课堂，哪些是我补充的

**课堂原有（原样保留）：** 题目；素材（火车站、儿时好友、偶遇的场景、帽子/影子/人影）；曾经的霸凌与冲突；由此引出“成长”；三个追问（体现什么主题／成长体现在哪里／过去的他和现在的他有什么不同）；成长是儿时朋友面对霸凌与现在冲突时的反应对比；过去（害怕、逃避、沉默、不敢表达）与现在（冷静、勇敢、主动解决）；时间线与地点线；回忆连接；六种描写手法；动作例子（低头、躲避目光、双手紧握／抬起头、直视对方、主动开口）；“说话吞吞吐吐”；提纲七项要求。

**我补充的（请审阅，可删改）：**
- 第 2 页把素材做成“零散碎片”，并用“要体现作者一个关于什么的思想”作追问措辞（按您的描述设计）。
- 第 3 页整页（“没有目的 / 有了目的”对比）；其中“它决定哪些素材留下、哪些删掉、放在哪里”是我对主题作用的概括，不是课堂原话。
- 题目不单独做读题页，放在第 2 页副标题里；备注里写了读题和画要求的做法。
- 第 4 页追问措辞（“这样的经历，能体现什么主题？”等）与点击顺序。
